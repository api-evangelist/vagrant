HashiCorp has introduced project-level run tasks for HCP Terraform, now in public beta, allowing organizations to enforce security, compliance, and operational controls consistently across groups of workspaces. Run tasks applied at the project scope are automatically inherited by any workspace created or moved within that project, reducing manual configuration overhead. This capability helps platform teams maintain governance consistency as infrastructure scales without per-workspace setup.
